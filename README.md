# 📱 Landing Page - Venta de Celulares, Accesorios y Servicio Técnico

Plantilla de landing page moderna, orientada a alta conversión y optimizada para **Mobile-First** y **SEO Local**, diseñada para tiendas de tecnología, comercialización de smartphones, accesorios y centros de servicio técnico especializado.

---

## 🎨 Paleta de Colores

* **Color Primario (Acento y CTAs):** Rojo intenso (`#E50914` / `#D32F2F`) para botones de llamada a la acción y elementos clave.
* **Color Secundario / Estructura:** Negro profundo y gris grafito (`#121212` y `#18181B`) para contraste prémium y apariencia tecnológica.
* **Color de Fondo:** Blanco puro (`#FFFFFF`) y gris claro (`#F4F4F5`, `#FAFAFA`) para limpieza visual y destaque de catálogo.
* **Color de Texto:** Grafito oscuro (`#121212`, `#27272A`) para lectura cómoda y accesible.

## 🚀 Características Principales

1. **Header Principal:**
   - Barra de navegación rápida, distintivo de atención y botón directo de contacto.
2. **Sección Hero:**
   - Propuesta de valor clara, métricas de confianza y doble llamada a la acción (cotización y catálogo).
3. **Módulos de Servicio & Catálogo:**
   - Venta de Smartphones (equipos nuevos, garantizados y homologados).
   - Accesorios (cargadores rápidos, fundas de protección y audio).
   - Servicio Técnico (reparación de pantallas, reemplazo de baterías y mantenimiento).
4. **Cotizador Rápido Interactivo:**
   - Formulario ágil que permite seleccionar marca, modelo y servicio deseado, formateando automáticamente la consulta hacia canales de mensajería (WhatsApp).
5. **Beneficios y Garantías:**
   - Bloques con iconos destacados de envíos, garantía por escrito y tiempos de entrega.
6. **Canales de Atención Directos:**
   - Botón flotante persistente de WhatsApp y enlaces directos de llamada y correo.
